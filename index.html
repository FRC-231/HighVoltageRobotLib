HighVoltageRobotLib

A WPILib vendor library maintained by FRC Team 231 (High Voltage). This site serves the Maven repository and the vendordep JSON.

Install

Download the vendordep JSON into your robot project's vendordeps/ directory and rebuild:

curl -O https://frc-231.github.io/HighVoltageRobotLib/HighVoltageRobotLib.json
mv HighVoltageRobotLib.json vendordeps/
./gradlew build
